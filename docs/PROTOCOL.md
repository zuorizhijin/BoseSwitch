# BMAP 协议笔记

本文只记录在真机上验证过的内容。设备：Bose QuietComfort 45（固件 4.0.4）、QuietComfort 35 II。
测试用的原始收发字节在 `fixtures/` 里，其中的蓝牙地址和设备名已匿名化。

## 传输

- 控制通道是蓝牙 RFCOMM，QC45 和 QC35 II 都在 **8 号频道**。
- 8 号频道没有在 SDP 里公布。所以只能按频道号直连，Chrome Web Serial 这类按服务 UUID 连接的方式连不上。
  - QC45 在 SDP 里公布的 `00000000-deca-fade-deca-deafdecacaff` 是 iAP2 通道，连上后收到的是 `ff 55 02 00 ee 10`，不是 BMAP。
  - 不要碰 24 号频道（SRfcomm）。它很可能用于固件更新，资料来源是 kaledcorona/bose-rfcomm 的警告。
- 连接后先发 `00 01 01 00`，读取 BMAP 版本。QC45 收到这条之后，才会回应其他请求。这条的回包可能晚到，要按「功能块.功能」匹配回包，不能按到达顺序。
- 打开控制通道本身不占耳机的连接名额。在 Windows 上打开 RFCOMM 会建立蓝牙基带连接，但不会连音频；macOS 会顺带把音频连过来。

## 包格式

```
[功能块] [功能] [标志] [载荷长度] [载荷 ...]
标志的低 4 位是操作符：
  0 SET    1 GET    2 SETGET   3 STATUS   4 ERROR
  5 START  6 RESULT 7 PROCESSING
```

- GET 的回应是 STATUS；出错时回 ERROR，载荷第一个字节是错误码。
- START 用来触发动作，耳机先回 PROCESSING。动作有没有生效，要重新 GET 读回状态，不能只看是否回了 PROCESSING。
- 已遇到的错误码：`03` 不支持该功能块，`05` 不支持该操作，`08` 运行时错误（名额已满时连接第三台设备）。

## 通用信息

| 请求 | 含义 | 回包载荷示例 |
|---|---|---|
| `00 01 01 00` | BMAP 版本 | `"1.1.0"`（QC45）、`"1.0.4"`（QC35 II） |
| `00 03 01 00` | 产品 ID | `40 39 01` = 0x4039，变体 1 |
| `00 05 01 00` | 固件版本 | ASCII 字符串 |
| `01 02 01 00` | 设备名称 | 首字节 `00`，之后是 UTF-8 名称 |
| `02 02 01 00` | 电量 | 首字节是百分比，如 `5a` = 90% |

## 降噪

**QC45（0x4039）**：用 AudioModes 功能块 31。
- 读当前模式：`1f 03 01 00`，回包载荷 `[模式序号]`。
- 切换：`1f 03 05 02 <序号> <提示音>`。序号 0=安静，1=感知；提示音 0=静默，1=播放语音提示。
- 用户在耳机上按键切换时，耳机会主动推送 `[31.3] STATUS`。

**QC35 II（0x4020）**：不支持功能块 31（回错误 03），用 ANR 功能 `[1.6]`。
- 读：`01 06 01 00`，回包载荷 `[当前档位, 支持位图]`。实测为 `01 0b`。
- 写：`01 06 02 01 <档位>`（SETGET）。档位 1=强，3=弱，0=关。

## 设备管理（功能块 4）

| 请求 | 含义 |
|---|---|
| `04 04 01 00` | 设备列表：载荷首字节是已连接位图，后面每 6 字节一个 MAC。离线的已配对设备也在列表里。 |
| `04 05 01 06 <mac>` | 单台设备详情：MAC(6) + 标志(1) + 2 字节 + 名称。标志 bit0=已连接，bit1=是发问的本机，bit2=Bose 自家产品（名称前多 1 字节）。 |
| `04 01 05 07 00 <mac>` | 让耳机连接这台设备（带前导 `00`） |
| `04 02 05 06 <mac>` | 断开这台设备（不带前导 `00`，带了会被拒绝） |

已验证的行为（QC45）：

- 耳机最多同时连 2 台设备。两个名额都满时：
  - 用 `04 01` 让耳机连第三台，耳机回 ERROR `08`。
  - 第三台电脑连控制通道都打不开，Windows 报 10060 超时。
  - 耳机不会自动断开任何一台。
- 断开本机（`04 02 05 06 <本机 MAC>`）后，耳机会立刻切断和本机的整条连接，后面的命令发不出去。所以「交给另一台电脑」只能分两步：A 机断开自己，B 机再连接。
- 「已连接」标志在本机只开着控制通道时也是 1，所以它不能证明音频已经连到本机。
